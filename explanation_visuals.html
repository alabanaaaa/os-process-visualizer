01. Program vs. Process

A Program is just a file on your disk. A Process is that program actually running in memory.

📄
THE PROGRAM
WINWORD.EXE
(Blueprint)
Disk Storage. Static. Shared.
🏗️
THE PROCESS
PID: 1024
(Instance)
Active RAM. Dynamic. Private.

When you open Word twice, the OS uses the same blueprint to build two different buildings.

02. Virtual Addressing

Each process believes it owns the entire memory. The OS maps these "fake" addresses to real physical RAM.
