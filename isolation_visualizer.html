Both processes load the same code, but create separate private worlds in RAM.

The Core Concept: When you open a second document, the OS doesn't just "add a window." It creates a entirely new Process.

This means that if Document 1 crashes, the memory for Document 2 is untouched. They are isolated. Each has its own independent address space, its own cursor, and its own unsaved changes.
